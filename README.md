- 🧪 Pruebas automatizadas utilizando Pytest.
- 🐳 Contenerización mediante Docker.
- 📋 Organización y especificación de cambios con OpenSpec.
- 🔧 Gestión de código mediante Git y GitHub.

- 📁 Publicación de artefactos.
